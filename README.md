# FlashyTube private F-Droid repo

Add this repo in the F-Droid app (Settings → Repositories → +):

```
https://baheay.github.io/flashytube-fdroid/fdroid/repo
```

Then install and update FlashyTube from F-Droid. Builds are signed with the
developer's own key, so they update in place over the channel/Drive builds.
